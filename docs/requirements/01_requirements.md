# 動画付き自己紹介プラットフォーム 要件定義書 v5.0

## 1. プロジェクト概要

### 1.1 サービス概要
ユーザーが動画を使った自己紹介ページを作成・公開できるプラットフォーム

### 1.2 目的
動画を活用した魅力的な自己紹介ページを誰でも簡単に作成できるようにする

### 1.3 ターゲットユーザー
- フリーランス
- クリエイター  
- ポートフォリオサイトを持ちたい個人

### 1.4 規模
- 個人開発
- 想定ユーザー数: 100人程度

---

## 2. 技術要件

### 2.1 使用技術スタック
- **バックエンド**: Laravel 11.x + PHP 8.2
- **フロントエンド**: Blade + Tailwind CSS + Alpine.js
- **ビルドツール**: Vite
- **データベース**: MySQL 8.0 (アプリ本体) / PostgreSQL + pgvector (チャットボット専用)
- **ローカル開発環境**: Docker
- **インフラ**: AWS (EC2, S3, RDS, Bedrock)
- **IaC**: CloudFormation (本番環境のインフラ構成管理)
- **動画処理**: FFmpeg
- **AI/LLM**: AWS Bedrock (Amazon Nova Lite + Titan Embeddings v2)
- **ライブラリ**: getID3（動画メタデータ取得）, aws/aws-sdk-php (Bedrock呼び出し)
- **テスト**: Pest, Playwright

### 2.2 インフラ方針
- ローカル開発はDockerで環境構築
- 本番環境はCloudFormationによるインフラのコード管理
- 開発環境と本番環境をパラメータで切り替え
- 最小コスト構成 (t3.micro, db.t3.micro等)
- S3から動画を直接配信 (CDNは将来的に導入)

### 2.3 動画エンコード方針
- **Phase 1 (MVP)**: EC2上でFFmpegによる同期エンコード
- **Phase 2 (将来)**: ECS + Lambda による非同期エンコード

## 3. ユーザー要件

### 3.1 ユーザー種別

| 種別 | 役割 | 人数想定 |
|------|------|----------|
| 管理者 | プラットフォーム管理 | 1名 |
| 一般ユーザー | 自己紹介ページ作成者 | 100名程度 |
| 未認証ユーザー | 公開ページ閲覧者 | 無制限 |

### 3.2 権限要件

#### 管理者
- 全ユーザーの自己紹介ページの閲覧・編集・削除が可能
- ユーザーアカウントの管理が可能
- プラットフォーム全体の設定管理が可能

#### 一般ユーザー
- 自分の自己紹介ページを作成・編集・削除できる
- 自分がアップロードした動画を管理できる
- 自分のアカウント情報を編集できる

#### 未認証ユーザー
- 公開された自己紹介ページの閲覧のみ可能

## 4. 機能要件

### 4.1 認証機能

#### 必須機能
- 新規ユーザー登録 (名前 + メールアドレス + パスワード)
- オープン登録 (誰でも自由に登録可能)
- ログイン / ログアウト

#### 任意機能 (将来)
- メール認証
- パスワードリセット (メール経由)
- SNS連携ログイン

### 4.2 公開ページ機能

#### URL構造
- 各ユーザーの自己紹介ページ: `/users/{ユーザーID}`

#### 表示内容
- ユーザー名
- 経歴 (テキスト、改行対応)
- サムネイル用動画 (円形枠、画面右下配置)
- ポップアップ表示用動画 (サムネイルクリック時にカード内フルカード展開再生)

#### 動画再生仕様
- **サムネイル動画**: 自動ループ再生、ミュート
- **ポップアップ動画**: クリック時にカード内フルカード展開再生、音声あり

### 4.3 管理ページ機能 (一般ユーザー)

#### アクセス要件
- 認証必須
- ユーザーは自分のページのみ編集可能

#### 編集可能項目
- 名前 (必須、50文字以内)
- 経歴 (任意、1000文字以内)
- サムネイル用動画 (任意)
- ポップアップ表示用動画 (任意)
- テーマカラー (プリセット8色から選択)

#### その他機能
- 公開前のプレビュー表示

### 4.4 動画アップロード機能

#### アップロード制限
- ファイルサイズ: 100MB以内
- 動画の長さ: 1分以内
- 対応フォーマット: mp4, mov, avi, wmv など一般的な動画形式

#### エンコード要件
- 出力形式: mp4 (H.264/AAC)
- 最大解像度: 1080p
- エンコード中は処理中表示
- エンコード失敗時は再試行またはエラー通知

#### ストレージ要件
- 動画はS3に保存
- ユーザー別にフォルダ分け
- 元動画はエンコード完了後に削除
- パブリック読み取り可能 (直接配信のため)

### 4.5 チャットボット機能

#### 概要
ログイン後のユーザー向けに、操作ヘルプFAQに回答するAIチャットボットを提供する。RAG(Retrieval-Augmented Generation)方式で、プロジェクトのドキュメント(`docs/`)を知識源とする。

#### アクセス要件
- 認証必須（`auth` middleware）
- 全画面共通の右下フローティングボタンから起動
- ユーザー毎にレート制限（10リクエスト/分）

#### 機能要件
- FAQ質問に対する自然言語回答
- マルチターン会話（直近5件の履歴を文脈として参照）
- 類似度閾値を下回った場合は「わかりません」応答（ハルシネーション抑制）
- 会話履歴の保存・表示

#### スコープ外（Phase 2以降）
- ユーザー個別データ参照（プロフィール・動画状態等のTool Use）
- ハイブリッド検索（BM25併用）
- 過去履歴全体の検索

#### 制約
- 入力: 2000文字以内
- 出力: 500トークン以内
- 応答時間: 10秒以内目標

### 4.6 管理者専用機能

#### ユーザー管理
- 全ユーザーのリスト表示
- 各ユーザーの自己紹介ページを編集・削除
- ユーザーアカウントの有効化/無効化

## 5. データ要件

### 5.1 必要なデータ

#### ユーザー情報
- 名前
- メールアドレス
- パスワード (ハッシュ化)
- 権限 (admin / user)
- アカウント作成日時

#### プロフィール情報
- ユーザーID (紐付け)
- 名前 (公開ページ表示名)
- 経歴
- サムネイル動画URL
- ポップアップ動画URL
- テーマカラー (HEX形式、プリセット8色)
- 動画表示順序 (JSON配列)
- 公開状態フラグ (is_public)
- 作成日時・更新日時

#### チャットボット情報
- チャット履歴 (user_id, role, content, 参照チャンクID, 作成日時) ※ MySQL側
- FAQチャンク (source_path, content, 埋め込みベクトル, トークン数, 更新日時) ※ PostgreSQL側

### 5.2 データ保持要件
- 削除されたユーザーのデータは30日後に完全削除
- 動画ファイルはユーザー削除と同時に削除

- 動画のスムーズな再生
- 同時アクセス: 50-100ユーザー程度に対応

### 6.3 可用性要件 (将来)
- データベースの自動バックアップ
- S3のバージョニング
- CloudFrontによる動画配信の高速化

### 6.4 運用要件
- CloudWatch によるログ収集・監視
- リソース使用率の監視 (CPU、メモリ、ストレージ)
- エラー発生時のアラート通知

## 7. 制約事項

### 7.1 技術的制約
- EC2インスタンスのスペック制限により、同時エンコードは1件まで
- アップロードタイムアウト: 最大5分
- エンコードタイムアウト: 最大5分

### 7.2 コスト制約
- 月額運用コスト目標: $30以下
- 最小コストのインスタンスタイプを使用
- 開発中はリソースを適宜停止してコスト削減
- チャットボット用PostgreSQLはスナップショット運用で利用時のみ復元（月額$2程度）
- Bedrock利用料は月$1〜$3程度（Nova Lite採用前提）

### 7.3 運用制約
- 不適切コンテンツの監視は管理者による手動確認
- サポート対応は管理者1名のみ

## 10. リスクと対策

### 10.1 技術的リスク

#### エンコード処理の負荷
- **リスク**: 複数ユーザーの同時エンコードでサーバー負荷増大
- **対策**: キューで1件ずつ処理、将来的にLambdaへ移行

#### 大容量ファイルのアップロード
- **リスク**: タイムアウトやメモリ不足
- **対策**: 100MB/1分の制限、適切なタイムアウト設定

#### エンコード失敗
- **リスク**: 特定フォーマットのエンコード失敗
- **対策**: 3回までリトライ、失敗時はユーザーに通知

### 10.2 運用リスク

#### 不適切コンテンツ
- **リスク**: 規約違反動画の投稿
- **対策**: 通報機能、管理者による削除機能

#### ストレージコスト増大
- **リスク**: ユーザー増加によるS3コスト増加
- **対策**: 定期的な使用量監視、削除ユーザーのデータ自動削除

#### サーバー障害
- **リスク**: EC2/RDS停止によるサービス停止
- **対策**: CloudWatch監視、アラート設定、将来的にマルチAZ化

## 12. 用語集

| 用語 | 説明 |
|------|------|
| サムネイル用動画 | 自己紹介ページに常時表示される短い動画 |
| ポップアップ用動画 | サムネイルクリック時にカード内フルカード展開で再生される動画 |
| エンコード | 動画を指定形式(mp4)に変換する処理 |
| CloudFormation | AWSリソースをコードで管理するサービス |
| FFmpeg | オープンソースの動画変換ツール |
| RAG | Retrieval-Augmented Generation。外部知識源から検索した情報を基にLLMが回答を生成する手法 |
| 埋め込み(Embedding) | テキストを数値ベクトルに変換する処理。類似度計算に使用 |
| pgvector | PostgreSQLの拡張機能。ベクトル型と類似度検索を提供 |
| AWS Bedrock | AWSが提供するマネージドLLMサービス |
| Amazon Nova | AWS自社製のLLMモデルファミリー |
